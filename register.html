N3X // NETWORK

Registriere deinen Style.

Deine Minecraft-UUID ist deine öffentliche N3X-ID. Über diese UUID laden kompatible N3X-Clients dein zugewiesenes Network-Cape.

Zur N3X Website
UUID eingeben und Network-Status prüfen.
Wie funktioniert das?
GitHub Pages liefert die öffentlichen Profile und Cape-PNGs aus. Andere N3X-Spieler laden dein Cape über network/v1/capes/<UUID>.png. GitHub Pages kann selbst keine sicheren Schreibzugriffe ausführen; neue Registrierungen werden deshalb aktuell als GitHub Issue angelegt und danach vom N3X-Admin freigeschaltet. Dein Microsoft-/Minecraft-Passwort wird niemals abgefragt.
