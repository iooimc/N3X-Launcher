Warum öffnet sich GitHub?
GitHub Pages kann selbst keine Formulardaten speichern. Solange N3X keinen eigenen Backend-Server hat, wird die Anfrage deshalb als GitHub Issue angelegt. Du brauchst dafür einen kostenlosen GitHub-Account. Dein Microsoft-/Minecraft-Passwort wird niemals abgefragt.
