04 // MANAGED STATIC API

Lesen öffentlich. Schreiben nur als Admin.

Der Launcher und die Mod lesen ohne Geheimnisse. Änderungen werden ausschließlich über das Admin Panel mit deinem persönlichen GitHub-Zugriff vorgenommen.

CONFIGnetwork/config.json
CAPESnetwork/capes/catalog.json
USERSnetwork/users/index.json
Admin-Kontrolle

Dein GitHub-Schreibtoken wird niemals im Launcher oder in der Mod eingebettet. Das Admin Panel fragt ihn nur für deine aktuelle Browser-Sitzung ab. Öffentliche Cape-Zuweisungen liegen unter network/v1/capes/<uuid>.png.
