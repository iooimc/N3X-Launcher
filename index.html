04 // STATIC API

Einfach per HTTPS lesen.

Die erste Network-Version ist bewusst read-only. So braucht der Launcher keinen geheimen GitHub-Token. Schreiben kommt später über eine kleine signierte Serverless-Bridge.

CONFIGnetwork/config.json
CAPESnetwork/capes/catalog.json
USERSnetwork/users/index.json
Warum noch read-only?

Ein GitHub-Schreibtoken darf niemals im Launcher oder in der Mod eingebettet werden. Jeder könnte ihn extrahieren. Deshalb lesen Clients jetzt sicher öffentlich; Upload/Select-Sync wird später über eine kleine authentifizierte Bridge ergänzt.
