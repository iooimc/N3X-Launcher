01 / FEATURES

Built around the things a launcher should do well.

↗

Microsoft sign-in

Authentication is performed through Microsoft using a public-client OAuth flow. N3X never asks for your Microsoft password.

◆

Vanilla instances

Create separate Minecraft instances with their own worlds and settings while sharing common game downloads.

⌁

Automatic Java

N3X can select and download a suitable Java runtime so players do not have to manage Java manually.

◫

RAM controls

Configure memory per launcher profile without digging through command-line JVM arguments.

◎

Diagnostics

Startup logging and clear error handling make early builds easier to test and troubleshoot.

＋

More to come

Fabric, mod support, updater tooling and additional quality-of-life features are planned for later builds.

N3X is designed as a public desktop client. It does not embed a client secret and does not collect Microsoft account passwords. Persistent authentication data is intended to use Windows-provided secure storage where available.
