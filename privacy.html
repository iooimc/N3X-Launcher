PRIVACY & SECURITY

Simple by design.

N3X Launcher is an independent Minecraft: Java Edition launcher for Windows. This page summarizes the privacy and security goals of the current alpha.

Microsoft authentication

N3X does not ask users to type their Microsoft password into the launcher. Authentication is completed through Microsoft using an OAuth 2.0 public-client flow. N3X does not embed a client secret.

Authentication data

Account tokens are not intended to be exposed to the launcher UI. Persistent authentication data is designed to use Windows-provided secure storage where available. Users can sign out to remove the locally stored login state.

Minecraft access

N3X is intended only for users who already have a valid Minecraft: Java Edition entitlement. It does not provide access to Minecraft without a valid license.

Project status

N3X is currently an early alpha. Features and implementation details may change before a general public release.

Disclaimer
